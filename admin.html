💾 Publicar cambios

Los cambios se guardan en este navegador. Para que los vea todo el mundo, descarga el archivo datos.js y súbelo a tu hosting (GitHub/Netlify) reemplazando el anterior.

🚀 Cómo publicar (3 pasos)

  1. Haz clic en “Descargar datos.js actualizado” (se guarda en tu carpeta de Descargas).
  2. Ve a tu repositorio en github.com → js/datos.js → lápiz ✏️ → borra todo, pega el contenido nuevo → Commit changes.
  3. Espera 1 minuto: el sitio público se actualiza solo.

Las fotos subidas desde este panel quedan guardadas dentro del archivo datos.js (funciona perfecto hasta ~40 fotos). Para muchas fotos, súbelas a la carpeta imagenes/eventos/ y escríbenos las rutas.
